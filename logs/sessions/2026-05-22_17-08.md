[2026-05-22 17:08] [ERROR]
錯誤訊息：Supabase HTTP 401: Forbidden use of secret API key in browser.
發生位置：Places GAS 使用 `sb_secret_*` 呼叫 Supabase REST API。
根本原因：Supabase 將 Google Apps Script 的 `UrlFetchApp` 請求判為 browser-like 環境。
解決方式：加入 `User-Agent`、`X-Client-Info`、`muteHttpExceptions` 後仍失敗；依使用者指示先保留現狀。
學習點：`sb_secret_*` 不一定適合 Apps Script 直接呼叫，後續可改回 legacy `service_role` JWT 或使用後端中介。
